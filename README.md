# 绿血的拯救 · 网页动画短片

原作者的小说《绿血的拯救》（尼尔·盖曼《绿字的研究》克苏鲁番外，六章约 1.07 万字）改编的纯前端网页动画短片。序幕（前情提要+片名）+ 六幕 + 尾声，约 10 分钟。

## 快速开始

- **看动画**：双击 `启动.bat`（自动起本地 TTS 服务器并打开页面），或直接访问 http://127.0.0.1:8945/
- **操作**：点击 / 空格推进剧情；右上角可切章节、自动播放、配音声源、语速、音效开关
- **录自己的配音**：点"🎙 录我的"进入工作台，103 句逐句录制（存在浏览器本地）

## 功能

- 剪影角色 + **"影子慢半拍"机制**（Rig 历史缓冲，全片视觉母题，5 处变奏）
- 12 个场景（地下室/剧院/酒馆/卧室/王子房间/伦敦夜景/贝克街 221B 等），静态层预渲染 + 动态灯光
- **镜头语言**：8 个关键镜头的 lookAt+缩放关键帧运镜
- **中英双语字幕**（中文打字机 + 英文副行），六张荒诞广告牌也双语
- **配音三引擎**：神经网络语音（Edge TTS，14 声源可选）／本机系统声／用户自己的录音（IndexedDB 持久化）
- 分层情绪音乐：底噪按幕切换情绪垫（平静→诡秘→恐惧→紧张→高潮→静默），WebAudio 全合成
- 音效全合成：底噪/心跳/滴水/烧纸/四下敲门（一声一停）/小提琴警告/重音
- 后台广播剧模式：切到后台自动转低频推进，配音照常

## 技术要点

纯 HTML/CSS/JS，零外部素材（画面全代码绘制，音效 WebAudio 即时合成，语音即时合成）。Canvas 2D @1280×720 逻辑分辨率（DPR 自适应）。详见 [AGENTS.md](AGENTS.md)（架构/机制/踩坑）。

## 已知限制

- 神经网络配音需本地 `server.py` 在线（纯静态托管自动回退本机声源）
- "我的声音"录音存于浏览器 IndexedDB，按域名隔离（换域名/设备需重录）
